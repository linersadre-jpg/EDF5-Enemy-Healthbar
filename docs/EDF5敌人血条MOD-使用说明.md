# EDF5 敌人血条 MOD —— 使用说明

**当前版本：v1.0.8**（已冻结存档：`snapshots\v1.0.8-20261010\`）

## 1. 安装与启动

```
E:\SteamLibrary\steamapps\common\EARTH DEFENSE FORCE 5\Mods\Plugins\EDF5EnemyHealthBar.dll
```

放进去即可，ModLoader 会自动加载（和现有的 `Patcher.dll` 一样）。
**第一次进游戏后**同目录会自动生成 `EDF5EnemyHealthBar.ini` 与 `EDF5EnemyHealthBar.log`。

- 改 ini 后需**重新进关卡**（或重启游戏）才生效；热键开关立即生效。
- **显示模式必须用「无边框窗口」或「窗口化」**，独占全屏下看不到血条。
- 更新 DLL 前先删掉旧的 `.log`，方便看新日志。

## 2. 它做什么

敌人头顶画一条血条，**以下条件全部满足**才画：

1. 敌人活着（当前血量 > 0）；
2. 敌人没满血（满血完全不画）；
3. 在视野内（半角默认 60°）；
4. 没被**建筑/地形**挡住（默认开；友军等角色单位不算遮挡）。

血量读的是对象里的 **总血量** `+0x1F8`(最大) / `+0x1FC`(当前)——实测普通兵 80.9、
巨型敌人 108154 都在同一对字段里。

## 3. 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `Enabled` | 1 | 总开关 |
| `ToggleKey` | 0 | 开关热键的 VK 码，`0` = 不设。例：F8 = `0x77`，F9 = `0x78`。**热键是三态的**：全开 → 只采集不画（对照用）→ 全关 |
| `BarColor` | 00FF00 | 血条颜色 RRGGBB（血量 > `LowHpPercent` 时用） |
| `BarColorMid` / `BarColorLow` | FFFF00 / FF0000 | 低血量 / 濒死时的颜色 |
| `LowHpPercent` / `CriticalHpPercent` | 60 / 20 | 上面两个颜色的触发百分比 |
| `BarWidth` | 42 | 血条宽（像素） |
| `BarHeight` | 7 | 血条高（像素） |
| `BarOutline` | 1 | 深色描边，明亮场景下更清楚 |
| `BarOutlinePx` | 2 | 描边厚度（像素），0~4 |
| `BackgroundAlpha` | 150 | 背景不透明度 0..255，0 = 不画背景。**可读性主要靠它** |
| `BarWidthByMaxHp` | 0 | 1 = 血条长度随最大血量 sqrt 缩放（夹 1~3 倍） |
| `BarScaleByDistance` / `DistanceRef` | 0 / 30.0 | 1 = 血条整体随距离缩小（夹 0.5~1 倍），参考距离 `DistanceRef` 米 |
| `MaxViewAngle` | 60 | 视野半角（度） |
| `OcclusionCheck` | 1 | 遮挡检测总开关 |
| `OcclusionIgnoreCharacters` | 1 | `1` = 友军/任何角色单位不算遮挡，只有地图建筑才挡血条 |
| `OcclusionReuse` | 2 | 遮挡结果分帧复用（同一对象每 N 帧才重投一次射线） |
| `OcclusionSelfFrac` | 0.90 | 命中比例 ≥ 该值算打到目标自身，不算遮挡（大型建筑型目标必需） |
| `OcclusionSamples` | 0 | 遮挡射线采样点数：`0` = 自动（大目标 2 点、其余 1 点），也可手填 1~3 |
| `OcclusionSampleStep` / `OcclusionSampleMinHp` | 12.0 / 1000 | 采样点抬升米数 / 自动模式启用多点采样的血量门槛 |
| `OcclusionFaultPolicy` | 0 | 射线异常时的策略：`0` = 保守（异常即暂停遮挡判定，换关卡再试）；`1` = 旧行为（重建 Havok 现场后继续） |
| `ShowOnDamageSec` | 3.0 | 最近 N 秒内掉过血的敌人**跳过遮挡判定**（正在挨打的目标一定看得见），0 = 关 |
| `BarScreenClamp` | 1 | 把血条屏幕位置夹在视口内（贴近/洞穴里不会顶出画面） |
| `MaxDistance` | 0 | 最大显示距离（米），0 = 不限 |
| `MinScreenSize` | 0 | 屏幕上的最小身高（像素），0 = 不限 |
| `MaxBars` | 64 | 同屏最多画几条 |
| `HeightOffset` | 2.0 | 锚点再往上抬多少米 |
| `ScaleHeightByMaxHp` | 1 | 血量越厚抬得越高（夹 1~3 倍，巨型/Boss 的条不会埋进身体里） |
| `UseLockOnPoint` | 1 | 优先用游戏自己的锁定点当锚点 |
| `DrawFps` | 0 | 覆盖层重绘上限；`0` = 不限，跟随游戏帧（推荐） |
| `EyeHeight` | 1.5 | 遮挡射线起点：玩家眼睛离地高度（米） |
| `RayFilter` | 0x16 | 遮挡射线的碰撞过滤。`0x16` 是**游戏自己多处使用的值**（另有 `0x17`），`0` = 打一切 |
| `OcclusionBackoff` | 0.0 | 射线终点往回收的距离（米）。`0` = 保持实测正常的行为，别乱动 |
| `OverlayMode` | 0 | `0` = 跟随游戏窗口；`1` = 覆盖整个桌面（窗口找不准时用） |
| `Debug` | 0 | 往同目录写日志（排查时设 1；日志超过 8MB 会自动截断重开） |
| `PerfLog` / `PerfIntervalMs` | 0 / 3000 | 输出 `[perf]` 性能统计（分阶段耗时 / 覆盖层线程 CPU / 帧间隔） |
| `DrawBars` | 1 | `0` = 不画自绘血条（采集照常），对照测试用 |
| `ExtraObjectScan` | 0 | 分帧扫描"带血量块"的表外目标（备用方案，白名单不可信，**默认关**） |
| `NativeProbe` | 0 | 仅调试：原生血条调研探针（会明显卡顿） |

> 关于 `RayFilter`：早先版本这里写的是"只与地图/建筑/地形碰撞（忽略所有角色）"，
> **那句话没有验证过**，已在 v1.0.8 的 ini 里更正。友军不挡血条由
> `OcclusionIgnoreCharacters` 显式保证，不再依赖 `RayFilter` 的语义。

## 4. 日志怎么读

`EDF5EnemyHealthBar.log`（UTF-8，无缓冲）：

| 行 | 含义 |
|---|---|
| `会话开始 本地时间 2026-10-17 00:11:20` | 每行的 `[+秒数]` 都是**距这一行**的秒数；崩溃时用它和事件查看器的时间对齐 |
| `构建标记: EHB-1.2.1 …` | 确认跑的是哪个版本 |
| `config:` / `config2:` / `config3:` | 实际生效的全部配置（`config3` 是 v1.2.1 新增的遮挡/显示键） |
| `[world] … vtable = hkpWorld，采用` / `[world] 世界更新 <旧> -> <新>` | 物理世界指针（换关卡会更新） |
| `[occl] 已为渲染线程建立私有 Havok 线程内存` + `[occl] 遮挡射线可用` | 遮挡可用的标志 |
| `[occl] 挡住 <敌人ptr> class=… 距离=… 命中比例=… 命中对象=<ptr> class=… 判为角色=0/1` | 谁挡住了血条（最多 40 行） |
| `[occl] 射线异常第 N 次：按保守策略…暂停遮挡射线，切换关卡后自动再试一次` | 射线出过异常，遮挡判定已暂停 |
| `[occl] 关卡切换（第 N 关）：恢复遮挡射线（本场累计异常 M 次）` | 换关卡后自动恢复 |
| `[frame N] 敌人条=X 队伍表对象=Y 遮挡射线=Z 遮挡命中=W` | 每 600 帧一条统计（`遮挡射线` 数的是射线条数） |
| `[hp] 新对象 … class=… max=… cur=…` / `[hp] … a -> b` | 血量取证：对象类名与总血量变化（**仅在 `Debug=1` 时输出**） |
| `[bar] 画 <ptr> class=…` | 真正画出来的条属于哪个类（仅在 `Debug=1` 时输出） |
| `[life] 关卡切换（队伍表清空）：已清空遮挡缓存与取证表` | 关卡切换时清空的缓存 |
| `[hotkey] 血条 状态=0全开/1只采集不画/2全关` | 热键切换 |
| `[perf] … 前置=… 遍历=… 遮挡=… 发布=…` | 性能统计（`PerfLog=1` 时每 `PerfIntervalMs` 一组） |
| `[!!] 采集异常 #N code=… addr=… (EDF5.exe+0x…) 对象=%p class=%s 距离=… 采样=… 世界=… 帧=… 关卡#…` | 出过异常。**这一行带完整现场，请原样保留**（最多 40 行） |

## 5. 出问题怎么排查

一条血条都不出现：

1. `Enabled=1` 了吗？热键是不是被按成关了？
2. 敌人是满血吗？（满血不画）
3. 试试 `MaxViewAngle=120`、`OcclusionCheck=0`、`MaxDistance=0`、`MinScreenSize=0`。
4. 日志里 `队伍表对象=0` → 还没进关卡 / 关卡里没有敌人。
5. 日志里 `敌人条=0` 但 `队伍表对象>0` → 被过滤掉了，看上面的四项配置。

血条穿墙显示：

- 把 `OcclusionIgnoreCharacters` 改成 `0`；
- 如果还是穿墙，把 `OcclusionCheck` 设成 `0`（彻底关掉遮挡），并把 `[occl] 挡住` 行发出来。

遮挡完全不工作 / 某一局中途消失：

- 日志里找 `[occl] 射线异常第 N 次` 与 `[!!] 采集异常`；
- **v1.2.1 起默认是保守策略**（`OcclusionFaultPolicy=0`）：射线出一次异常就**暂停**遮挡判定
  （血条照画，只是不再判遮挡），**切换关卡时自动恢复重试一次**；整场累计 3 次则永久关闭到重开游戏。
- 旧行为（`OcclusionFaultPolicy=1`：丢世界 + 重建私有 Havok 线程内存后继续，最多 3 次）风险更高：
  异常可能已经弄坏了游戏的数据结构，之后游戏自己走过去才崩 —— **不推荐**。

游戏"卡死几秒然后闪退"：

- 这通常**不是两个问题**，而是同一次崩溃：未处理异常触发 WER 收集转储时进程被挂起数秒（= 卡死），
  转储写完进程才结束（= 闪退）。
- 请保留 `Mods\Plugins\EDF5EnemyHealthBar.log`，把 `[+秒数]` 前缀与"会话开始 本地时间"对上事件查看器
  里 `EDF5.exe` 的崩溃时间；如果日志里有 `[!!] 采集异常` 行，那一行就是关键证据。

## 7. 卸载

删掉 `Mods\Plugins\EDF5EnemyHealthBar.dll` 与 `EDF5EnemyHealthBar.ini`。
本 MOD **不修改游戏任何文件、不向游戏代码写补丁**。
