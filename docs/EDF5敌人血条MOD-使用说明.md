# EDF5 敌人血条 MOD —— 使用说明

**当前版本：v1.0.8**（已冻结存档：`snapshots\v1.0.8-20261010\`）

## 1. 安装与启动

```
E:\SteamLibrary\steamapps\common\EARTH DEFENSE FORCE 5\Mods\Plugins\EDF5EnemyHealthBar.dll
```

放进去即可，ModLoader 会自动加载（和现有的 `Patcher.dll` 一样）。
**第一次进游戏后**同目录会自动生成 `EDF5EnemyHealthBar.ini` 与 `EDF5EnemyHealthBar.log`。

- 改 ini 后需**重新进关卡**（或重启游戏）才生效；热键开关立即生效。
- **显示模式必须用「无边框窗口」或「窗口化」**，独占全屏下看不到血条。
- 更新 DLL 前先删掉旧的 `.log`，方便看新日志。

## 2. 它做什么

敌人头顶画一条血条，**以下条件全部满足**才画：

1. 敌人活着（当前血量 > 0）；
2. 敌人没满血（满血完全不画）；
3. 在视野内（半角默认 60°）；
4. 没被**建筑/地形**挡住（默认开；友军等角色单位不算遮挡）。

血量读的是对象里的 **总血量** `+0x1F8`(最大) / `+0x1FC`(当前)——实测普通兵 80.9、
巨型敌人 108154 都在同一对字段里。

## 3. 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `Enabled` | 1 | 总开关 |
| `ToggleKey` | 0 | 开关热键的 VK 码，`0` = 不设。例：F8 = `0x77`，F9 = `0x78` |
| `BarColor` | 00FF00 | 血条颜色 RRGGBB |
| `BarWidth` | 50 | 血条宽（像素） |
| `BarHeight` | 5 | 血条高（像素） |
| `BarOutline` | 1 | 1px 深色描边，明亮场景下更清楚 |
| `BackgroundAlpha` | 0 | 背景不透明度 0..255，0 = 不画背景 |
| `MaxViewAngle` | 60 | 视野半角（度） |
| `OcclusionCheck` | 1 | 遮挡检测总开关 |
| `MaxDistance` | 0 | 最大显示距离（米），0 = 不限 |
| `MinScreenSize` | 0 | 屏幕上的最小身高（像素），0 = 不限 |
| `MaxBars` | 64 | 同屏最多画几条 |
| `HeightOffset` | 2.0 | 锚点再往上抬多少米 |
| `ScaleHeightByMaxHp` | 1 | 血量越厚抬得越高（巨型/Boss 的条不会埋进身体里） |
| `UseLockOnPoint` | 1 | 优先用游戏自己的锁定点当锚点 |
| `DrawFps` | 60 | 覆盖层帧率 |
| `EyeHeight` | 1.5 | 遮挡射线起点：玩家眼睛离地高度（米） |
| `RayFilter` | 0x16 | 遮挡射线的碰撞过滤。`0x16` 是**游戏自己多处使用的值**（另有 `0x17`），`0` = 打一切 |
| `OcclusionBackoff` | 0.0 | 射线终点往回收的距离（米）。`0` = 保持实测正常的行为，别乱动 |
| `OcclusionIgnoreCharacters` | 1 | `1` = 友军/任何角色单位不算遮挡，只有地图建筑才挡血条 |
| `OverlayMode` | 0 | `0` = 跟随游戏窗口；`1` = 覆盖整个桌面（窗口找不准时用） |
| `Debug` | 1 | 往同目录写日志 |

> 关于 `RayFilter`：早先版本这里写的是"只与地图/建筑/地形碰撞（忽略所有角色）"，
> **那句话没有验证过**，已在 v1.0.8 的 ini 里更正。友军不挡血条由
> `OcclusionIgnoreCharacters` 显式保证，不再依赖 `RayFilter` 的语义。

## 4. 日志怎么读

`EDF5EnemyHealthBar.log`（UTF-8，无缓冲）：

| 行 | 含义 |
|---|---|
| `构建标记: EHB-1.0.8 …` | 确认跑的是哪个版本 |
| `config:` / `config2:` | 实际生效的全部配置 |
| `[world] … vtable = hkpWorld，采用` / `[world] 世界更新 <旧> -> <新>` | 物理世界指针（换关卡会更新） |
| `[occl] 已为渲染线程建立私有 Havok 线程内存` + `[occl] 遮挡射线可用` | 遮挡可用的标志 |
| `[occl] 挡住 <敌人ptr> class=… 距离=… 命中比例=… 命中对象=<ptr> class=… 判为角色=0/1` | 谁挡住了血条（最多 40 行） |
| `[frame N] 敌人条=X 队伍表对象=Y 遮挡射线=Z 遮挡命中=W` | 每 600 帧一条统计 |
| `[hp] 新对象 … class=… max=… cur=…` / `[hp] … a -> b` | 血量取证：对象类名与总血量变化 |
| `[bar] 画 <ptr> class=…` | 真正画出来的条属于哪个类 |
| `[!!] 采集异常 …` | 出过异常（遮挡会自动关闭） |

## 5. 出问题怎么排查

一条血条都不出现：

1. `Enabled=1` 了吗？热键是不是被按成关了？
2. 敌人是满血吗？（满血不画）
3. 试试 `MaxViewAngle=120`、`OcclusionCheck=0`、`MaxDistance=0`、`MinScreenSize=0`。
4. 日志里 `队伍表对象=0` → 还没进关卡 / 关卡里没有敌人。
5. 日志里 `敌人条=0` 但 `队伍表对象>0` → 被过滤掉了，看上面的四项配置。

血条穿墙显示：

- 把 `OcclusionIgnoreCharacters` 改成 `0`；
- 如果还是穿墙，把 `OcclusionCheck` 设成 `0`（彻底关掉遮挡），并把 `[occl] 挡住` 行发出来。

遮挡完全不工作 / 某一局中途消失：

- 日志里找 `[occl] 射线异常第 N 次` 与 `[!!] 采集异常`；
- 射线异常已做 3 次容错（自动丢弃旧世界 + 重建 Havok 线程内存），连续 3 次才永久关闭。

| 转视角时血条略微跟不上模型 | 已知。覆盖层按 `DrawFps`(60) 定时重绘，游戏帧率更高时不匹配 → 见 `EDF5-血条延迟与卡顿-分析与优化方案.md` |

| ~~传送塔这类目标没有血条~~ | **已修复**（`OcclusionSelfFrac`）；详见 `EDF5-排查手册-某类目标没显示血条.md` |

## 7. 卸载

删掉 `Mods\Plugins\EDF5EnemyHealthBar.dll` 与 `EDF5EnemyHealthBar.ini`。
本 MOD **不修改游戏任何文件、不向游戏代码写补丁**。
