# EDF5 敌人血条 MOD — P0 只读探针 使用说明

这个探针**只读内存**：不挂钩、不打补丁、不写游戏内存。它每 0.5 秒把游戏里的
队伍表、敌人对象、血量字段、坐标与相机矩阵记一行到日志里，用来确认静态逆向得到的
地址是否对得上真实运行的游戏。

## 一、装进去（两步）

1. 把这两个文件复制到游戏的插件目录：

   ```
   build\EDF5EnemyHealthBarProbe.dll
   src\EDF5_Probe.ini
   ```

   目标目录（没有就自己建）：

   ```
   E:\SteamLibrary\steamapps\common\EARTH DEFENSE FORCE 5\Mods\Plugins\
   ```

2. **建议先给游戏目录加一个 Windows Defender 排除项**（设置 → 病毒和威胁防护 →
   排除项 → 添加文件夹 → 选游戏根目录）。EDFModLoader 和这类注入 DLL 常被误报；
   你自己编译的 DLL 也可能被拦，加了排除项更稳。

## 二、跑一局

1. 正常启动 EDF5。
2. 进一关，**打一会儿**：至少打伤几只敌人（探针主要看的就是受伤敌人），
   能遇到不同种类更好（步兵 / 大型敌人 / 无人机都行）。
3. 建议跑 **1~2 分钟**就够（默认采 600 个快照 / 约 5 分钟后自动停笔）。
4. 退出游戏。

## 三、把日志发回来

日志在插件目录下：

```
E:\SteamLibrary\steamapps\common\EARTH DEFENSE FORCE 5\Mods\Plugins\EDF5_Probe.log
```

把它复制到工作区（或者告诉我路径我自己读）：

```
F:\deepseek-harness\default-workspace\EDF5_Probe.log
```

如果游戏目录里出现 `ModLoader.log`，也一并给我 —— 它能确认探针有没有被加载。

## 四、探针在验证什么

| 编号 | 待验证 | 日志里的样子 |
|---|---|---|
| 1 | 队伍表全局 `EDF5.exe+0x125AB80` → `+0x38` 行数组 / `+0x48` 队伍数 | `[snap N] mgr=... rows=... teamCount=...` |
| 2 | 队伍 map 的遍历（head / 根 +0x08 / key +0x20）是否列出对象 | `team T: relation=... objects=N` |
| 3 | 血量三兄弟 `+0x1F4 / +0x1F8 / +0x1FC` 哪个是最大/当前 | `hp cur/max/min=...` 与 `血量邻域` |
| 4 | 对象类名（RTTI）── 哪些是敌人、哪些是子弹 | `obj=... class=.?AV...` |
| 5 | 位置到底在 `+0x90` 还是 `+0xA4` | `posA(0x90)=... posB(0xA4)=...` |
| 6 | 世界转屏幕算得对不对 | `scr=(x,y)` 是否落在窗口内、深度是否正确 |
| 7 | 队伍 +0x218 与玩家所在队伍 | `team(new0x218)=...`、`player ... team=...` |

## 五、日志怎么看（我这边看的重点）

- `teamCount` 应该是 2~8 之间；`rows` 必须非空。
- 敌对队伍的 `relation` 应该是 `2`；`objects=N` 应该和屏幕上看到的敌人数目量级一致。
- 敌人对象的 `class` 应该不是 `Bullet`、`Effect` 之类。
- 敌人的 `hp cur` 应该随着你射击**减少**，`max` 保持不变 —— 这就是最大的确认信号。
- `posA(0x90)` 与 `posB(0xA4)` 里，**只有一个**会给出合理的屏幕坐标（在你打的那个
  敌人身上），另一个会是乱的。这就直接确定了坐标偏移。

## 六、出问题怎么办

- **游戏没反应 / 日志没生成**：先看 `ModLoader.log` 里有没有
  `Loading Plugin: ...EDF5EnemyHealthBarProbe.dll`。没有的话是 DLL 没被加载
  （多半是 Defender 拦了）。
- **游戏崩溃**：删掉 DLL 即可恢复。探针的所有读取都先做 `VirtualQuery` 校验，
  设计上不该崩；真崩了请把崩溃时机告诉我（进关卡前 / 关卡中 / 退出时）。
- **日志太大**：把 `EDF5_Probe.ini` 里的 `RawDump` 改成 `0`，`Snapshots` 改成 `60`
  再跑一次。
